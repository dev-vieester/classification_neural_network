# Classification Neural Network

A beginner-friendly PyTorch project that demonstrates binary classification using a synthetic dataset generated by `scikit-learn`.

This repository contains a Jupyter notebook that walks through the full workflow of building, training, and evaluating a neural network for a non-linear classification problem.

## Project Goal

The main goal of this project is to show how a neural network can learn to separate two interleaving classes using a simple 2D dataset. The dataset is generated with `make_circles`, which is a classic example where a linear model is not enough and a neural network can learn the decision boundary.

## Why This Project Matters

This project is useful for learning:

- how to generate synthetic classification data
- how to prepare data for PyTorch
- how to build a neural network with `torch.nn`
- how to define a loss function and optimizer
- how to split data into training and testing sets
- how to evaluate predictions and basic model performance

## Key Features

- Synthetic dataset generation using `scikit-learn`
- Data exploration with `pandas`
- Visualization with `matplotlib`
- PyTorch tensor conversion for model training
- Simple feedforward neural network architecture
- Binary classification with sigmoid output and BCE loss
- Notebook-based learning workflow for educational use

## Dataset

The model uses the `make_circles` dataset from scikit-learn.

- Input features: 2 numerical values (`X1`, `X2`)
- Output labels: binary classes (`0` and `1`)
- Sample size: 1000 data points
- Distribution: balanced class labels

This dataset creates two concentric circles, making it a good example of a non-linear classification problem.

## Model Architecture

The notebook builds a simple feedforward neural network with:

- Input layer: 2 features
- Hidden layer: 5 neurons
- Output layer: 1 neuron for binary classification

The network uses:

- `nn.Linear` layers
- `BCEWithLogitsLoss()` for binary cross-entropy
- `torch.optim.SGD` as the optimizer

## Training Workflow

The notebook includes the following steps:

- generate the circles dataset
- inspect the first samples and labels
- create a DataFrame for easier analysis
- plot the dataset
- convert NumPy arrays into PyTorch tensors on the GPU/CPU
- split the data into train and test sets
- define the model architecture
- train the model with SGD
- compute predictions and apply a sigmoid function
- round predictions for binary classification output
- evaluate accuracy and observe the learning process

## Expected Outcome

The model should learn a curved decision boundary that separates the two classes. Since the dataset is non-linear, this is a good demonstration of why neural networks are useful for more complex classification tasks.

## Example of the Problem

The generated data resembles two rings of points, where one class occupies the inner circle and the other occupies the outer circle. A standard linear classifier would not correctly separate these classes, while a small neural network can learn the structure.
